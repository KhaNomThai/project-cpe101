# 🕸️ Visualization of Prim’s Algorithm

An **interactive web application** that demonstrates how **Prim’s Algorithm** works in finding a **Minimum Spanning Tree (MST)**.  
This project serves as an **educational tool** for students and learners to visualize each step of the algorithm, making it easier to understand how graph traversal and edge selection operate in real time.

---

## 🎯 Features
- Step-by-step visualization of Prim’s Algorithm  
- Interactive graph creation (add/remove nodes and edges)  
- Highlighted edge selection during MST construction  
- Real-time cost updates and algorithm progression  
- Clean and minimal user interface for learning clarity  

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript  
- **Library:** D3.js (for visualization)  
- **Framework (optional):** React (if applied)  
- **Algorithm Implemented:** Prim’s Minimum Spanning Tree (MST)

---

## 📚 Purpose
This project was developed as a **learning tool** to help students in computer science and engineering visualize the inner workings of graph algorithms — specifically **Prim’s Algorithm**, which is often challenging to grasp through text alone.
